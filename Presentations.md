# Presentations

## Requirements, Evidence and Attestation Traceability with Python and Flexo
*JAXA MBSE Symposium · Tsukuba · June 12, 2026*
*Presented by Michael Zargham*

This talk demonstrated a live Marimo notebook delivering reproducible evidence with full provenance, using a vendor-neutral semantic spine (PROV · EARL · OntoGSN · SysMLv2 OWL · SHACL · P-PLAN · OSLC). It distinguished between evidence produced by behavior-model oracles and human attestation (adequacy + sufficiency, per Hawkins–Habli), showing that only attestation links evidence to requirement satisfaction. Live push to a Planetary Utilities-hosted Flexo MMS instance provided end-to-end provenance across ASoTs, with code in git, RDF in Flexo, and runtime in Docker.

## What does the GKC Framework frame? A constituent's view of governance
*Governing Generative AI as Knowledge Commons Workshop · June 18, 2026*
*Prepared and presented by D. Sisson*

This talk built a functional architecture for knowledge-generating systems (Data → Information → Knowledge → Decision) and argued that any such system requires a regulatory element to remain viable. The architecture situates the GKC Framework in the Regulation zone of a cognitive system — alongside OODA as alternative instantiations — and shows the same layered structure appearing across silicon-based, carbon-based, and community-based systems. The perspective was drawn from DSG's ongoing work on decision support systems and distributed knowledge processing.
